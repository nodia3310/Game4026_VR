# A 的 VR 互動試玩指南

想試「拿武器 → 打敵人 → 放回文物 → 引出法老」，請開 **InteractionTest**。沒有頭顯也能用鍵盤和滑鼠跑完整段流程。

## 開始試玩

1. 在 GitHub Desktop 按 **Fetch origin**，切到 `feature/vr-interaction`，有更新就按 **Pull origin**。首次下載請先完成專案的 [Git LFS 與 Unity 設定](../README.md)。
2. 用 Unity **6000.6.7f1** 開啟專案，等匯入完成。在 Project 視窗開啟 [InteractionTest.unity](../Assets/A_VRInteraction/Scenes/InteractionTest.unity)。用 Quest 時先讓頭顯進入 Quest Link，再按 **Play**；用桌面時直接按 **Play**，然後點一下 **Game** 視窗。
3. 面向工具桌，先拿右半邊的手電筒照向右後方白牆。能看見光斑，就已經會抓取和使用道具了。

| 我要做什麼 | Quest 控制器 | 桌面 |
| --- | --- | --- |
| 走動、轉向 | 左搖桿移動，右搖桿分段轉向 | WASD 移動，按住滑鼠右鍵拖曳轉向 |
| 把手移到握柄 | 用任一隻手靠近道具 | Tab 切換活動手；方向鍵左右、上下移手，R 向前、F 向後 |
| 拿起、放開 | 按住側邊 Grip 抓取，鬆開即放手 | Q 抓取，再按 Q 放手 |
| 開關手電筒、發射射線 | 持有時按食指 Trigger | 持有時按 E |

## 從武器桌走到法老出場

| 在哪裡試 | 怎麼做 | 成功時會看到什麼 |
| --- | --- | --- |
| **近戰** · 工具桌左半邊 | 拿刀、斧、撬棍或鏟子揮向左前方的靶。桌面用 Shift 搭配移手鍵加快揮擊。再到房間後方，從阿努比斯側後方揮向軀幹，避開牠手上的短刀。 | 靶閃黃，狀態板顯示揮擊速度。打中阿努比斯身體時，牠頭頂的血量會下降。 |
| **投斧與接回** · 同一把斧頭 | Quest 揮出斧頭時鬆開 Grip；桌面拿斧瞄準後按 E。斧頭撞到目標後會飛回原手，聽見提示音或感到短震時，用原手再按一次 Grip（桌面按 Q）。 | 接準時斧頭回到手中。漏接會掉到地上，靠近握柄可再撿起。 |
| **射線與雙手弓** · 工具桌右半邊 | 射線工具瞄準靶後按 Trigger 或 E。用弓時，一手握住弓柄，另一手抓住藍色弦珠、後拉，再放開拉弦手。桌面依序用 Q 拿弓、Tab 換手、移手到弦珠、Q 抓弦、F 後拉、Q 放弦。 | 射線會被牆擋住；弓會射出實體箭。要試弱點傷害，可把箭射向阿努比斯頭部。 |
| **文物歸位** · 右側及左後方底座 | 卡諾卜罐在右側；羅塞塔石碑、圖坦卡門面具在左後方。照標籤把每件放到對應藍色托盤中心，鬆手並稍等。三件的順序可自行決定。 | 放對的文物會吸附鎖定。第三件就位後，法老會在右後方出現一次；若站在生成點旁，退開至少 3 公尺。 |

停止後重新按 **Play**，即可重置血量、文物和遭遇戰，再交給下一位組員試玩。

## 在博物館試哪些項目

[Museum.unity](../Assets/Scenes/Museum.unity) 的西側互動展區可以試近戰、射線、弓、手電筒與陶罐歸位；Quest 按左手 **X** 可切換蹲下與站起，方便撿地上的工具。投斧接回、固定站位的阿努比斯、三件文物引出法老，請到 **InteractionTest** 體驗。正式展廳的武器與敵人出場位置見[博物館出場計畫](../Docs/MuseumEncounterPlan.zh-TW.md)。

要把新敵人或展櫃接進場景，可查[接線方式與測試紀錄](../Docs/InteractionTest.zh-TW.md)及 [B 給 A 的傷害與文物介面說明](NOTES_FOR_A.md)。這版通過 251 項 Edit Mode 與 39 項 Play Mode 測試，新增的敵人與法老流程仍待 Quest 3 真機驗收。
