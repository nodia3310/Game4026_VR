# Museum_Demo 交接報告｜2026-11-23

**試玩入口**　用 Unity **6000.6.7f1** 開啟 [Museum_Demo](../Assets/_Game/Scenes/Demo/Museum_Demo.unity)。本次交付位於 `feature/vr-interaction`。Quest 玩家先比對地面黃圈，按右手 **A** 完成開場地面確認。

| 更新 | 組員如何複測 | 預期結果 |
| --- | --- | --- |
| 巡查板弱點圖鑑 | 空手走近交班桌上的巡查板，進入約 2 公尺範圍。看到半透明 **X** 提示後，按左手 **X** 開啟，再按一次關閉。用 Grip 抓住右頁往左翻過書脊後放開；抓左頁往右可翻回。桌面用滑鼠左鍵點巡查板開啟，在書頁上點左鍵往後翻、右鍵往前翻，點 **CLOSE** 關閉。 | 閱讀時隱藏玩家血量，關書或走離時恢復顯示目前血量。先按住 X 再靠近時，放開並重新按下才會開書。 |
| 手持近戰的傷害範圍 | 用刀、斧、撬棍或鏟子分別以柄尾、握點、中段和尖端揮擊測試靶。四件武器可在 [InteractionTest](../Assets/A_VRInteraction/Scenes/InteractionTest.unity) 集中測試。 | 整段武器參與揮擊判定，啟動速度為 1.2 m/s，掃掠半徑為 3.5 公分。有效揮擊對同一目標只結算一次。超出柄尾及側面範圍的對照靶應保留原血量。 |
| 首波生怪倒數 | 先空手走離出生點，再拿起武器開始計時。倒數途中放下並重拿武器，觀察第一隻怪出現的時間。 | 空手移動可自由探索。第一次拿起近戰武器或弓後滿 **30 秒遊戲時間**才可生成第一隻怪。再次拿起武器不會重算；玩家死亡重開後重新走一次流程。 |

## 已驗證與待驗收

- **巡查板**。開書先顯示展廳與法老戰的弱點跨頁，再往後是原有八頁圖錄。模擬手柄已驗證左手 X 開關、Grip 往返翻頁，以及閱讀中受傷後，關書會顯示最新血量。Quest 3 Link 真機已觀察到 Grip 拖頁、閱讀時隱藏血量，以及走離後自動收書並恢復 100 HP 顯示。該輪開始記錄時書已打開，左手 X 的完整開關流程仍待真機補測。
- **近戰**。Unity 的逐點測試涵蓋四件武器的柄尾、握點、中段、尖端及兩個範圍外對照點。該次完整 Play Mode 回歸 **69/69**、近戰 Edit Mode **15/15** 通過。
- **首波生成**。開發時已在 Unity 驗證第 **29.99 秒**仍不可生成，到第 **30 秒**才可生成。場景中的 `DemoFlow.introDelay` 為 29 秒，[第一波的 Start Delay](../Assets/_Game/Data/Enemies/Demo/Wave_Demo_1.asset) 為 1 秒。若日後調整倒數，須一併計入兩段延遲。
- **Quest 3 真機接手順序**。先空手走到西側交班桌，看到 X 後按左手 X 開書，放開再按一次關書。接著拿武器開始計時，途中放下再拿起，記錄第一隻怪出現的時間。出怪後用柄尾和尖端分別揮擊，核對每一揮的扣血次數。先前測試生怪時曾觀察到 XR 互動套件的空值錯誤，若重現請記錄當時使用的手、操作與 Console 堆疊。
